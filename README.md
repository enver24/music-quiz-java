Music Quiz Project 🎵

A simple quiz game written in Java using Greenfoot.
Built as part of my Programming Fundamentals course.

Features
Two game modes:
Guess Count Game – user guesses how many song/artist combos are incorrect.
Song Quiz Game – user answers true/false for each combo.
Uses arrays, loops, methods, and input validation.
Console report cards with scoring and percentage.
Files
MusicQuizProject/src/MusicQuizActor.java – main game logic (song data, game modes, input handling and scoring)
How to Run
Open project in Greenfoot.
Create a new MusicQuizActor and add it to the world.
Click Act to play the game.
